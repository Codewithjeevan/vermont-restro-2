How to use the meal plan

A simple workflow, from creating a plan to serving meals, taking payments and closing the day. There is also a short example below for a manual check on fresh data.

Getting started

1

Set up Settings

Mess → Settings

Turn on the slots you serve (breakfast, lunch, dinner), then set their timings, the default cycle days and the alert window. This is also where you choose whether an open register is required to take payments.

2

Create a plan

Mess → Plans → Add Plan

Enter the name, Veg / Non-veg / Both, included meals, the price per person per full cycle and the cycle days. A plan is a price-list template; the actual charge is fixed on the subscription.

3

Add a member

Mess → Members → Add Member

Enter the name, phone, room/address, diet preference and pickup/delivery. The member code is generated automatically. One member can have many cycles.

4

Start a subscription

Mess → Subscriptions → New Subscription

Select the member and the plan. Check the number of persons for each meal slot, the start/end dates and the agreed price, then save. The suggested price is only a calculation; the Agreed Price is what gets billed.

If a plan includes more than one slot, the app divides the plan price by cycle days × included slots to get a per-meal rate, then works out the suggested amount from the selected persons and days. Always check the agreed price before saving.

Daily work

5

Plan the menu and quantities

Mess → Daily Menu

Set the dishes for each date, slot and Veg/Non-veg. Picking a Food Menu dish lets stock be calculated from its recipe; a free-text dish has no recipe-based stock movement. Enter the portion per person and the buffer.

6

Check the kitchen sheet

Mess → Daily Sheet

See the expected headcount, planned portions and any stock shortage. Print the sheet to give the kitchen its preparation list.

7

Mark meals

Mess → Meal Register

Pick the date and the breakfast/lunch/dinner slot, then mark each member as Served, Partial, Not taken or Skipped. Advance skips are recorded here too; use Add Extra for extra items.

8

Close the slot

Mess → Day Close

Check for pending meals. Enter the cooked and leftover quantity for each dish, choose what happens to the leftover (Waste / Carry to next meal / Staff meal), then close. Consumption and waste for recipe dishes are posted to the stock ledger.

Payment

In Mess → Payments → Receive Payment, enter the member, amount and method. With the default setting, the POS register must be open before you take money. The payment shows up in the register collection.

Renew / pause

Renew the next cycle from Mess → Subscriptions or Renewals. Pausing a subscription for a member's leave pushes its end date forward.

Reports

See Daily Summary, Attendance Matrix, Collection and Day Close / Food Cost in Mess → Reports. Unpaid balances are on the Dues tab.

Manual check on fresh data

  1. Save Settings and a test plan; check the price, slots and cycle days in the Plans list.
  2. Add a test member and create a subscription; verify the agreed price and dates.
  3. Set the Daily Menu for today's dinner; check the expected portions in the Daily Sheet.
  4. Mark the member as Served in the Meal Register; the counts should change.
  5. Open the register and record a payment; check the member balance and the collection.
  6. Run Day Close, then check the served count and food cost in Reports.
Note: A test payment is counted in the register close, and Day Close changes recipe-based stock. Use a test member, a test payment and a test dish for manual testing.
