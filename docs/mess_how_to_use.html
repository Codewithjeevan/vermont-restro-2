Poora flow, ek nazar mein

Pehli line setup hai. Dusri line roz ka kaam hai. Payment subscription ke baad kabhi bhi record kar sakte hain.

Shuru kaise karein

1

Settings set karein

Mess → Settings

Breakfast, lunch, dinner mein jo slots chalane hain unhein on karein; timings, default cycle days aur alert window set karein. Payment ke liye open register required hai ya nahi, ye bhi yahin hota hai.

2

Plan banayein

Mess → Plans → Add Plan

Naam, Veg / Non-veg / Both, included meals, price per person per full cycle aur cycle days bharein. Plan price list ka template hai; actual charge subscription mein final hota hai.

3

Member add karein

Mess → Members → Add Member

Naam, phone, room/address, diet preference aur pickup/delivery bharein. Member code apne aap banta hai. Ek member ke multiple cycles ho sakte hain.

4

Subscription shuru karein

Mess → Subscriptions → New Subscription

Member aur plan select karein. Har meal slot mein persons ki sankhya, start/end date aur agreed price check karke save karein. Suggested price sirf calculation hai; Agreed Price bill mein jata hai.

Roz ka kaam

5

Menu aur quantity plan karein

Mess → Daily Menu

Date, slot aur Veg/Non-veg ke liye dishes set karein. Food Menu dish select karne par recipe se stock calculation ho sakti hai; free-text dish mein recipe-based stock movement nahi hoga. Portion per person aur buffer bharein.

6

Kitchen sheet dekhein

Mess → Daily Sheet

Expected headcount, planned portions aur stock shortage dekhein. Print sheet se kitchen ko preparation list milti hai.

7

Meal mark karein

Mess → Meal Register

Date aur breakfast/lunch/dinner slot chun kar member ko Served, Partial, Not Taken ya Skipped mark karein. Advance skip bhi yahin record hota hai; extra item ke liye Add Extra use karein.

8

Slot close karein

Mess → Day Close

Pending meals check karein. Har dish ki cooked aur leftover quantity bharein, phir leftover ka Waste / Carry / Staff action chun kar close karein. Recipe wali dishes ka consumption aur waste stock ledger mein post hota hai.

Payment

Mess → Payments → Receive Payment mein member, amount aur method bharein. Default setting par paisa lene se pehle POS register open hona chahiye. Payment register collection mein dikhega.

Renew / pause

Mess → Subscriptions ya Expiring se next cycle renew karein. Member ki leave ko pause karne par subscription ki end date aage badhti hai.

Reports

Mess → Reports mein Daily Summary, Attendance Matrix, Collection aur Day Close / Food Cost dekhein. Dues tab mein unpaid balance milega.

Fresh data par manual check

  1. Settings aur ek test plan save karein; Plans list mein price, slots aur cycle days dekhein.
  2. Ek test member add karke subscription banayein; agreed price aur dates verify karein.
  3. Aaj ke dinner ke liye Daily Menu set karein; Daily Sheet mein expected portions dekhein.
  4. Meal Register mein member ko Served mark karein; counts badalne chahiye.
  5. Register open karke payment record karein; member balance aur collection check karein.
  6. Day Close karke Reports mein served count aur food cost dekhein.
Dhyan dein: Test payment register close mein aata hai; Day Close recipe-based stock ko affect karta hai. Manual testing ke liye test member, test payment aur test dish use karein.
